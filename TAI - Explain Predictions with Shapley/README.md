# TAI - Explain Predictions with Shapley

## Description

This custom step runs `PROC SHAPLEY` in SAS to compute Shapley values for explaining machine learning model predictions. The step examines a predictive model and shows how each input variable contributed to the model's predictions. This can help users understand which factors were most important and build confidence in model results.

The step supports two explanation methods:
- **HyperSHAP** — a fast approximation method optimized for tree-based models.
- **KernelSHAP** — a model-agnostic kernel-based approximation method for general models.

The step can help users:
- See which variables have the biggest impact on predictions.
- Understand the factors driving model decisions.
- Explain model results to business users, managers, auditors, or other stakeholders.
- Improve transparency when working with machine learning models.

By making model predictions easier to understand, this step helps users move beyond what the model predicted and better understand why the model made that prediction.

More information about `PROC SHAPLEY`: [PROC SHAPLEY documentation](https://go.documentation.sas.com/doc/cn/pgmsascdc/v_072/casml/casml_shapley_toc.htm)

## User Interface

### Design tab

- **Select Reference Data Table (Background Dataset)** — Select the reference data table that contains the background observations used by `PROC SHAPLEY`.
- **Specify Predicted Target Column** — Select exactly one numeric predicted target column that contains the model prediction values to explain.
- **Specify Interval Inputs** — Select one or more numeric interval input variables used by the predictive model.
- **Specify Nominal Inputs** — Select one or more nominal input variables used by the predictive model.

At least one input variable list must be populated. The user must select at least one interval input variable or at least one nominal input variable before the step can run successfully.

![TAI - Explain Predictions with Shapley Design Screen](images/shapley-design.png)

### Configuration tab

- **Analytic Store Model Table** — Optionally select an ASTORE model table. If an ASTORE table is provided, the step adds an `astoremodel` statement to `PROC SHAPLEY`. If no ASTORE table is selected, the step runs without the `astoremodel` statement.
- **Select a weight column** — Optionally select a numeric weight column. If populated, the step adds a `weight` statement to `PROC SHAPLEY`.
- **Explanation Method** — Choose the Shapley explanation method. Available options are `HyperSHAP` and `KernelSHAP`.

#### HyperSHAP Method Options

Visible when **Explanation Method** is set to `HyperSHAP`.

- **Maximum Depth of Coalitional Approximation** — Required integer value that controls the maximum depth used for the HyperSHAP approximation. The UI allows values from 1 through 2.

#### KernelSHAP Method Options

Visible when **Explanation Method** is set to `KernelSHAP`.

- **Bin Width for Interval Variables** — Required numeric value that controls the bin width used for interval variables. The default value is `0.1`.
- **Include missing values in calculations** — Optional checkbox that includes missing values in KernelSHAP calculations when selected.
- **Sample Size (Number of coalition samples)** — Required integer value that controls the number of coalition samples generated by KernelSHAP. The default value is `500`.
- **Random Seed** — Optional integer seed value used to make KernelSHAP sampling reproducible.
- **Use raw data for calculation** — Optional checkbox that tells KernelSHAP to use raw data when selected.

## Requirements

- Tested on SAS Viya version Stable 2026.05.
- Uses: `PROC SHAPLEY`.
- Requires a reference data table that contains the predicted target column and the input variables used to explain the prediction.
- Requires exactly one predicted target column.
- Requires at least one interval input variable or at least one nominal input variable.
- Optionally accepts an ASTORE model table.
- Optionally accepts a numeric weight column.

## Usage

- **Required inputs:** Reference data table, predicted target column, and at least one input variable list. The step requires at least one value in **Specify Interval Inputs** or **Specify Nominal Inputs**.
- If the reference data table, predicted target column, and both input variable lists are missing, the step does not execute `PROC SHAPLEY`. Instead, the source code writes the following error message to the SAS log:

```sas
ERROR: Missing required parameters. Please check your SAS Studio Flow inputs and Target Variable selection.
```

- Before running `PROC SHAPLEY`, the step creates `CASUSER._QUERY` by reading the first observation from the selected reference data table:

```sas
data CASUSER._QUERY;
    set &refData(obs=1);
run;
```

- The step then runs `PROC SHAPLEY` with `CASUSER._QUERY` as the data to explain and the selected reference data table as the background reference data.
- If **Analytic Store Model Table** is populated, the step performs:

```sas
astoremodel rstore=<astoreTable>;
```

- If **Analytic Store Model Table** is not populated, the step does not generate an `astoremodel` statement.
- If **Specify Interval Inputs** is populated, the step performs:

```sas
input <intervalVars> / level=interval;
```

- If **Specify Nominal Inputs** is populated, the step performs:

```sas
input <nominalVars> / level=nominal;
```

- The selected predicted target column is assigned through the `predictedtarget` statement:

```sas
predictedtarget <targetVar>;
```

- If **Select a weight column** is populated, the step performs:

```sas
weight <weightVar>;
```

### HyperSHAP usage

When **Explanation Method** is set to `HyperSHAP`, the step runs a `method hypershap` statement. If **Maximum Depth of Coalitional Approximation** is populated, the selected value is passed to the `depth=` option.

Example structure:

```sas
method hypershap (
    depth=<hyperDepth>
);
```

### KernelSHAP usage

When **Explanation Method** is set to `KernelSHAP`, the step runs a `method kernelshap` statement. Depending on the selected UI options, the step can pass bin width, missing-value handling, sample size, random seed, and raw-data behavior.

Example structure:

```sas
method kernelshap (
    binwidth=<kernelBinWidth>
    includeMissing
    sampleSize=<kernelSampleSize>
    seed=<kernelSeed>
    useRawData
);
```

The `includeMissing`, `seed=`, and `useRawData` options are included only when the corresponding UI fields are populated or selected.
